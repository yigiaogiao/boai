# BOAI

播客订阅、收件箱与收听工作台。首发目标平台是懒猫微服：Go 进程同源提供 React 前端和 JSON API，SQLite 负责持久化。

当前进度覆盖普通播客闭环和可选的 BYOK AI：真实 RSS／Atom 订阅、定时与手动更新、新单集进收件箱、音频播放／拖动／倍速／续听、分类、OPML 导入、来源逐字稿，以及文本模型生成的导读／精读／导图／译文／单集问答和按需云端转写。收件箱支持单集和批量的「标记已读／标为未读」「移出／移回收件箱」，我的订阅支持单个和批量「取消关注」，也能一次给多个节目设置同一个分类。列表行不再放三点菜单：桌面右击、手机长按打开操作菜单，收件箱可分享链接或把单集下载到本机；侧栏新增「下载」板块，可回看、分享和删除本地文件。收件箱和我的订阅都有内联搜索；侧栏的「继续收听」集中展示上次没听完的单集，收件箱顶部不再放「全部／未听／继续听」标签行。侧栏新增「订阅播客」板块，用来搜索公开目录、粘贴订阅链接、导入 OPML，并按 Apple Podcasts 中国区热门榜展示 12 个热门节目和最多 10 条热门节目最新一期；OPML 入口放在搜索框正下方。国内推荐在上，随后才是「海外热门 · 英文精选单集」栏目，按 Apple Podcasts 美国区科技榜和商业榜回查各榜位节目的最新一期，每个子栏最多 10 条，只保留 AI、科技、互联网与金融商业主题，只标榜位、不推算收听人数；点英文单集直接进入正常的单集播放详情。热门单集在桌面端也显示返回按钮；点单集详情里的节目封面或节目名可进入播主详情页，未订阅的试看节目同样适用。榜单卡片不再直接订阅：点节目进入节目详情页，可看介绍和节目列表后再订阅；从我的订阅打开节目时，中间的订阅列表会保留，播放单集时列表仍在、阅读区占第三栏；节目详情最多加载最近 120 集，长介绍默认折叠为三行并可展开。取消关注后会保留当前节目页和订阅按钮，可立即重新订阅，不再瞬间清空界面。侧栏「继续收听」显示未听完的单集数量，播放进度保存后会即时增减。单集页已按用户要求移除书签、标签入口和「资料库」面包屑，点击封面或节目名会进入该节目的详情页。AI 完全可选，不配置也能使用其余功能；界面先展示节目源内容，生成结果带可核对的时间点引用，证据不足会直接说明。无 Docker 的懒猫 LPK 候选包已经生成并通过本机 lint，但尚未上架，也未在懒猫真机验证。

## 环境

- Go 1.26 或更新版本
- Node.js 22 或更新版本（构建前端）
- 支持 WebAssembly 以外常规 Go 目标的 Linux／macOS 开发机

## 本地运行

```bash
# 构建前端（产物在 web/dist，Go 进程会直接托管）
cd web
npm ci
npm run build
cd ..

# 启动应用；默认 http://127.0.0.1:8080，数据写入 ./data
BOAI_ALLOW_PRIVATE_NETWORK=true go run ./cmd/boai
```

`BOAI_ALLOW_PRIVATE_NETWORK=true` 仅用于本机测试数据。它会让服务端允许访问回环地址，默认关闭，部署时不要开启。

如果本机或懒猫设备使用 fake-IP DNS（把公网域名解析到 RFC 2544 的 `198.18.0.0/15` 再由平台代理解析），设置 `BOAI_ALLOW_FAKE_IP_DNS=true`。它只对**主机名请求的 80／443 端口**放行这一个地址段；内网、回环、链路本地、云元数据地址和直接写 IP 的链接仍然拒绝，也不会放宽 `BOAI_ALLOW_PRIVATE_NETWORK`。懒猫 manifest 已开启这一项。

前端开发模式：

```bash
# 终端 1
BOAI_ALLOW_PRIVATE_NETWORK=true go run ./cmd/boai

# 终端 2；Vite 将 /api 代理到 127.0.0.1:8080
cd web
npm run dev
```

## 用测试数据走一遍

仓库的 `testdata/fixtures` 是独立测试源，不会被应用自动导入，也不会混进正式资料库。测试音频是 180 秒 WAV，每 15 秒换一个音高，便于确认拖动和章节跳转落在了哪里；需要重新生成时运行 `python3 testdata/fixtures/generate-audio.py`，并同步订阅源里的 `enclosure length`。

```bash
# 终端 1：带 Range 支持的静态文件服务，默认 127.0.0.1:8090
go run ./cmd/fixtureserve

# 终端 2
BOAI_ALLOW_PRIVATE_NETWORK=true BOAI_DATA_DIR=./data-dev go run ./cmd/boai
```

打开侧栏「订阅播客」，在搜索框粘贴 `http://127.0.0.1:8090/feed.xml` 并点「识别链接」，确认后订阅。应当看到：

- 节目「潮汐测试台」和 2 集单集进入收件箱
- 第 1 集有 3 个章节、VTT 逐字稿和 3 分钟音频
- 播放、拖动、倍速和刷新页面后的续听进度都保留

模拟新单集：

```bash
# 停掉 fixtureserve 后重新启动，改用更新版订阅源
go run ./cmd/fixtureserve -updated
```

再点应用里的刷新，第 3 集（SRT 逐字稿，2 个章节）会进入收件箱。

OPML 导入可使用 `testdata/fixtures/subscriptions.opml`：默认地址同样指向 8090，`fixtureserve` 会按请求地址重写其中的订阅链接。导入会并行确认订阅源（默认 8 个并发、单项 20 秒超时、单次最多 100 项），数据库写入保持串行；结果按 OPML 原顺序返回，已存在的订阅直接标记为 `existing`，不重复抓取。

## 测试与构建

```bash
go test ./...
go vet ./...

cd web
npm run build
```

`go test ./...` 覆盖存储、服务、HTTP API、SSRF 校验、RSS／Atom／OPML、逐字稿解析、媒体代理对伪装成音频的 HTML／SVG 内容的拒绝，以及使用本地假文本／语音供应商的 AI 生命周期：无 Key、文本与语音独立配置、来源逐字稿复用、引用校验、证据不足、任务去重与重试、重启中断恢复、删除 Key 保留历史、双用户隔离和 Key 不回传／不落明文。收件箱动作测试覆盖已读／未读、归档在播放和标未读后的粘性、节目页可见性、恢复状态推导和 owner 隔离；取消关注测试覆盖单个／批量、级联删除和跨用户保护；OPML 测试用带延迟的本地源验证并发抓取、结果顺序和重复导入。下载测试覆盖 SSRF 安全抓取、范围播放、0600 本地文件、下载文件名头、列表不暴露路径、跨用户 404、单个／批量删除、退订清理文件和删除后回退远端音频。订阅播客测试用本地假 Apple 榜单和查询接口校验榜位、最新单集、来源标签、15 分钟缓存，以及美国区科技／商业榜的去重、只接受 `podcastEpisode`、主题筛选和 10 条上限；节目详情测试校验未订阅节目以隐藏状态试看、不进入收件箱／订阅／状态计数，订阅后复用同一节目记录并进入收件箱；批量分类测试校验一次事务替换多个节目的分类、owner 隔离和跨用户 404。书签的界面、API 和存储方法都已移除，新建数据库也不再创建书签表；升级库中遗留的旧表不再被读取或写入，也不会自动删除。媒体代理测试覆盖播客统计服务常见的多级跳转链（当前上限 12 次，每一跳仍校验地址）和拒绝非音频内容；fake-IP 策略测试确认只有开启开关后，主机名在 80／443 端口才能使用 `198.18.0.0/15`，私网、元数据、直接 IP 和其它端口仍被拒绝；瞬时传输错误测试校验 GET 最多重试两次、持续失败仍会返回、策略错误不重试；状态接口测试确认 `in_progress` 随进度保存和完成即时变化；单集列表接口校验 `limit` 参数并限制在 1–500，节目详情固定请求最近 120 集；浏览器回归测试确认每 8 秒保存进度不会重建音频源，播放到 10.5 秒和 13.7 秒仍在继续。API 测试使用进程内的测试源，不需要外网、真实 Key 或固定端口。订阅播客的浏览器回归还确认国内板块排在英文之前、中文热门 10 条和英文两个子栏各 10 条；桌面单集详情显示返回按钮，收件箱阅读区不显示无意义的返回按钮；点节目封面或节目名能打开播主详情页，未订阅的试看节目同样可用。

## 收件箱与订阅操作

收件箱、「我的订阅」和「下载」共用列表的选择模式：桌面右击或手机长按任意行，在菜单里点「多选」进入；行首出现复选框，并自动勾选打开菜单的那一行。进入后出现批量操作条，也可以用「全选／清空选择」。批量条里始终有且只有一个「取消」，即使一项都没勾也能直接退出；标题栏不再提供重复的「选择／取消」入口。批量条不再做成浮起的卡片，而是和列表同底色、上下细线的两行纸面区域：第一行显示已选数量和取消，第二行是文字动作。收件箱和我的订阅的搜索框同样是一条细线下划线，不再嵌一个白色圆角输入框。

单行操作不占用行尾空间：桌面右击、手机长按（约 0.5 秒）打开定位在指针附近的菜单，也可用键盘 `ContextMenu` 或 `Shift+F10`；点空白、滚动、缩放或按 `Esc` 关闭。

- **收件箱菜单**：标记已读／标为未读；移出／移回收件箱；多选；分享（复制单集链接，没有单集链接时复制节目站点）；下载。菜单也保留在节目页的单集上。
- **收件箱批量条**：下载、标记已读、移出／移回收件箱。下载会按队列逐集保存，结束后刷新「下载」数量。
- **我的订阅菜单**：分类、多选、取消关注。工具栏的「分类」打开分类管理；批量条也能对勾选的多个节目一次性设置分类，保存后替换这些节目的全部分类。
- **下载菜单**：分享、删除下载、多选。批量条提供「删除下载」。删除会移除本机音频文件和下载记录，不会取消关注，也不会把单集移出收件箱。

行为约定：

- **标记已读**把单集标为完成并保留收听位置；**标为未读**恢复未听状态。**移出收件箱**只设置归档状态，不删除单集或进度；归档单集不再出现在收件箱里，但仍可在所属节目页找到并用「移回收件箱」恢复。播放进度和「标为未读」不会让归档单集重新回到收件箱。
- **继续收听**是侧栏的独立入口，等价于按「有进度且未听完」筛选；收件箱不再提供「全部／未听／继续听」标签行和分类 chip，分类筛选仍在侧栏「我的分类」。
- **下载**通过服务端的 `safehttp` 校验抓取音频（每次请求和重定向都只允许公开 HTTP(S)），单集上限 512 MiB，写入数据目录下按用户哈希隔离的 `downloads/`，文件权限 `0600`；同一单集重复下载是幂等的。已下载音频优先由本地文件播放，接口仍支持 Range／HEAD。列表接口不返回文件路径。
- **取消关注**会删除该节目及其单集、本地下载、收听进度、逐字稿和 AI 结果；节目详情页和「订阅节目」按钮会保留，可以立即重新订阅，但已删除的本地进度和历史不会恢复。分类本身保留。单个和批量都有确认提示。
- 列表选择状态会在切换收件箱／订阅／下载、筛选条件或进入节目单集时清空，避免对看不见的条目执行批量操作。

交互参考了 [Pocket Casts 的归档语义](https://support.pocketcasts.com/knowledge-base/archiving-episodes/)（归档隐藏但不删进度）和[多选批量动作](https://support.pocketcasts.com/knowledge-base/using-multi-select/)，以及 [AntennaPod 的节目级分类](https://antennapod.org/documentation/subscriptions/subscription-groups)；归档单集在本应用里仍留在节目页并标记「已移出」，比单独开「显示归档」更直接。行内操作改为右击／长按，是为了保持列表只展示播客内容本身；下载采用服务端文件而不是浏览器下载链接，才能在应用内列出、离线播放和真正删除本地文件。

## 搜索与订阅播客

收件箱和我的订阅的标题下各有一个内联搜索框，输入后约 260ms 自动筛选，不需要打开对话框。

- **我的订阅搜索**：只在已关注的节目里筛选，匹配节目名、主播／简介和分类名；结果是可点击的节目行，点开进入该节目的详情页。
- **收件箱搜索**：同时匹配单集标题、简介、所属节目名，以及服务端逐字稿全文命中；还包含节目名命中的整档节目。搜索的是本资料库，不会悄悄请求公开目录。清除搜索后恢复当前筛选。
- **订阅播客**：侧栏独立板块，搜索框用于**新增**订阅，走 Apple Podcasts 公开目录；也可以粘贴 RSS、Apple Podcasts 或分享链接，先识别来源再订阅。OPML 导入也移到这里，保留逐项结果。
- **推荐来源**：搜索框下方先放 OPML 导入，再依次展示「热门播客」「热门节目最新一期」和「海外热门 · 英文精选单集」。中文榜来自 Apple Podcasts 中国区公开热门榜（`itunes.apple.com/cn/rss/toppodcasts`）；英文栏来自 Apple Podcasts 美国区科技榜（genre 1318）和商业榜（genre 1321），不是只列节目名，而是用节目榜位回查每个节目的最新一期，分列 AI／科技／互联网与金融／商业单集，每个子栏最多 10 条；中文榜取前 10 个节目的最新一期。榜单本身混有综合节目，因此后端用节目名、主播、节目简介和最新单集标题筛选主题：科技栏要求 AI、科技或互联网信号，金融栏要求金融／市场信号；只有当 Apple 明确返回 `podcastEpisode` 时才展示为单集，节目自身的 `track` 结果会被跳过。Apple 公开接口提供的是**榜位**，不提供收听人数，因此界面只按榜单第 N 位标注，不展示或推算收听量；所有单集推荐都明确写「按节目榜位排序」。榜单在后端缓存 15 分钟，抓取失败时如实提示，搜索和粘贴链接仍可用。
- **节目详情页**：我的订阅、公开目录、热门播客和英文单集里的节目入口都只打开详情页，不再在第二个列表里套一个分类筛选。详情页展示封面、介绍、节目主页、单集数量和节目列表；本地订阅节目只读最近 120 集，避免一次渲染上千集；长介绍默认折叠为三行，可展开或收起，来源眉标不再重复显示。已订阅节目可以直接打开单集，未订阅节目可以试听，并在确认介绍和内容后点「订阅节目」。从我的订阅打开节目时桌面保留「侧栏＋订阅列表＋详情」三栏，播放单集时列表仍在、阅读区替换详情；手机仍是单列，返回后回到原列表。取消关注会删除下载和进度，但保留当前详情页和「订阅节目」按钮，可以立即重新订阅。试看节目先以隐藏状态保存，订阅前不会出现在收件箱、我的订阅、搜索或更新任务里。
- **直接播放**：点「热门节目最新一期」或英文精选单集的卡片会拉取该节目源、匹配同名单集并直接进入正常的播放详情页；如果节目源里找不到这一集，会停在节目详情页并提示。播放详情页在桌面端也显示「返回列表」，点节目封面、节目名或面包屑可进入播主详情页，未订阅的试看节目也能打开。

选择 Apple 榜单而不是 Spotify／YouTube 收听量，是因为后两者的收听数据依赖登录态或商业数据源，本应用在无 Key、无账号的前提下无法核实；Apple 的公开榜位可以稳定、可重复地读取。这不代表 Apple 的听众规模最大，也不做跨平台热度排名。

## 手机端与 WebView

界面为窄屏做了单列布局：收起侧栏与列表，单集详情用返回按钮回到收件箱；在 `620px` 以下，页面按安全区留出顶部和底部空间，主要按钮和标签至少 40–44px 高，播放器加大拖动条和传输按钮的触摸区域；`380px` 以下进一步压缩标题和封面。打开单集、打开对话框都会写入一条浏览器历史记录，所以应用内返回、浏览器返回和 WebView 的硬件返回都先回到上一级，不会直接退出应用。

## 懒猫微服候选包

打包沿用无 Docker 的 LPK v2 路线：`scripts/build-lpk.sh` 先构建前端，再把 linux/amd64 静态 Go 二进制、`web/` 和 CA 证书放进 `lazycat/content`，由 `lzc-cli` 生成 `content.tar`。运行时使用官方镜像 `registry.lazycat.cloud/lzc/lzcapp:3.20.3`，入口是 `/lzcapp/pkg/content/boai`。

```bash
# 需要 Go、Node.js 和 lzc-cli；GO 可指向自定义 Go 工具链
PATH=/path/to/go/bin:$PATH ./scripts/build-lpk.sh
```

产物是 `lazycat/dist/cloud.lazycat.app.boai-v0.1.11.lpk`（15,108,608 字节，SHA-256 `a07d4ad811f3b18cfbcc30af8e8c77224239fdcd5d0848ca91dc5019ac536d6d`）。构建脚本会检查二进制确实为静态链接，运行 `lzc-cli project lint`，并在本机存在可写的 `/lzcapp/document` 时自动把新包复制过去、校验内容一致；可用 `BOAI_SKIP_NETDISK_COPY=1` 跳过复制。当前 `0.1.11` 的构建、lint（无警告）、包内容和本机运行结果记录在 `lazycat/README.md`；旧的 `0.1.0` 至 `0.1.10` 包保留在 `dist/` 中，仅作对照。`0.1.11` 只把仓库和包元数据切换到 MIT 许可证，用户可见功能与 `0.1.10` 相同。

部署边界：

- `multi_instance: true`，每个用户一个容器，SQLite 和 AI 密钥位于该用户的 `/lzcapp/var/boai`。
- 只申请 `net.internet`，不读取网盘、不申请 `document.read`／`media.read`。
- 只信任网关注入的 `X-HC-User-ID`；缺少该头时 API 返回 `401`，不会回退到公共用户。
- manifest 不设置 `BOAI_ALLOW_PRIVATE_NETWORK` 或 `BOAI_ALLOW_INSECURE_AI`，安装后也保持关闭。
- manifest 设置 `BOAI_ALLOW_FAKE_IP_DNS=true`，用于懒猫把公网域名改写为 `198.18.0.0/15` 的 fake-IP DNS；只放行主机名的 80／443 端口，不放开内网、回环、链路本地和元数据地址。
- 构建成功后会自动把 `.lpk` 复制到 `/lzcapp/document/`，在懒猫客户端网盘里点开安装；不要自行发布商店。当前 `0.1.11` 已复制并通过 SHA-256 校验。真机验收清单见 `lazycat/README.md`。

## 配置

| 环境变量 | 默认值 | 说明 |
| --- | --- | --- |
| `BOAI_ADDR` | `127.0.0.1:8080` | HTTP 监听地址 |
| `BOAI_DATA_DIR` | `./data` | SQLite 与运行时数据目录 |
| `BOAI_WEB_DIR` | `./web/dist` | 前端构建产物目录 |
| `BOAI_UPDATE_INTERVAL` | `30m` | 定时刷新间隔，最小 1 分钟 |
| `BOAI_HTTP_TIMEOUT` | `30s` | 单次外部请求超时，最小 5 秒 |
| `BOAI_MAX_FEED_BYTES` | `16777216` | 订阅源响应上限，最小 64 KiB；默认 16 MB 以容纳大型节目源 |
| `BOAI_TRUST_USER_HEADER` | `false` | 是否信任网关传入的用户标识头 |
| `BOAI_USER_HEADER` | `X-HC-User-ID` | 网关用户标识头名称 |
| `BOAI_ALLOW_PRIVATE_NETWORK` | `false` | 是否允许访问内网地址；只用于本机测试 |
| `BOAI_ALLOW_FAKE_IP_DNS` | `false` | 是否允许主机名在 80／443 端口解析到 fake-IP 的 `198.18.0.0/15`；懒猫 manifest 已开启 |
| `BOAI_ALLOW_INSECURE_AI` | `false` | 是否允许 AI 供应商地址指向回环／内网；只用于本地假服务测试 |
| `BOAI_ITUNES_BASE` | `https://itunes.apple.com` | 公开节目目录接口地址 |
| `BOAI_SECRET` | 空 | AI Key 加密密钥；为空时在数据目录生成 `ai-secret`（0600） |

默认不信任用户头，所有请求归入 `local` 单一所有者。接入懒猫网关后由部署层打开 `BOAI_TRUST_USER_HEADER`，不同用户的数据按所有者隔离。

`BOAI_SECRET` 只用于派生 AES-256-GCM 密钥，不会写进日志或 API 响应。设置后请与数据目录一起备份；密钥变化会导致已保存的 AI Key 无法解密，需要重新填写。没有 `BOAI_SECRET` 时程序首次启动会生成 `ai-secret`，同样需要随数据目录保留。

## AI 配置与行为

AI 是可选的 BYOK 功能，文本模型和语音转写分开配置，各自使用 OpenAI 兼容接口：

- 文本模型：`/chat/completions`，用于导读、精读、导图、译文和「问这集」。
- 语音转写：`/audio/transcriptions`（`response_format=verbose_json`），只在本集没有可用来源逐字稿时使用。

在左下角「AI 服务」中填写 Base URL（例如 `https://api.example.com/v1`）、模型名和 API Key，可分别保存、测试和删除。Key 经 AES-256-GCM 加密后按用户存入 SQLite，接口只返回是否已配置、模型和地址，不会返回 Key；删除 Key 后历史生成内容和逐字稿仍然保留。

生成任务会明确显示供应商、发送的是文字还是音频，以及费用由供应商收取。任务写入 SQLite，页面可看到排队／处理中／失败／完成状态并重试；重复点击复用同一个进行中的任务，服务重启会把中断任务标为失败而不是永久卡住。音频只在用户主动发起云端转写时才上传，生成译文只发送原文文字，不重传音频。

测试阶段使用本地假供应商，不接触真实 Key：

```bash
BOAI_ALLOW_PRIVATE_NETWORK=true BOAI_ALLOW_INSECURE_AI=true \
  BOAI_DATA_DIR=./data-ai go run ./cmd/boai
```

`BOAI_ALLOW_INSECURE_AI` 与 `BOAI_ALLOW_PRIVATE_NETWORK` 相互独立：即使订阅源允许内网，AI 供应商地址仍走单独的公开网络校验。两项都只用于本机测试，部署时都不要开启。

当前只支持 OpenAI 兼容的文本和转写接口，未适配供应商特有的鉴权、模型列表或异步任务协议。单集音频上限 80 MiB；超过时提示无法云端转写。

本机和懒猫的 fake-IP DNS 会把部分公网域名改写为 `198.18.0.0/15` 再由平台代理。`safehttp` 默认仍拒绝这类地址；只有显式设置 `BOAI_ALLOW_FAKE_IP_DNS=true` 时，主机名请求在 80／443 端口才接受该段地址，直接写 IP、其它端口以及内网／回环／链路本地／元数据地址继续拒绝。这不是放宽私网限制：`BOAI_ALLOW_PRIVATE_NETWORK` 仍保持关闭。GET／HEAD 在拿到响应头之前遇到连接重置、EOF 等瞬时网络错误时最多重试两次，每次重新解析 DNS；地址策略错误和调用方取消不会重试。外部地址只允许公开 HTTP(S)，重定向、DNS 解析和请求都经过同一套校验，并限制响应大小和超时。

## 当前边界

- AI 依赖用户自己的 OpenAI 兼容供应商；没有内置额度、代理计费或模型路由，也不会回退到匿名共享 Key。
- 不做全库问答、独立发现页或桌面／手机壳。
- 下载是服务端保存的本地文件，不做跨设备同步、后台排队续传或下载质量转码；抓取失败会保留远端播放能力，不留下半截文件。删除下载只影响本机副本。
- 下载功能的 SSRF 校验、文件和删除逻辑已用本地 HTTP 测试源验证；真实公网播客的大文件下载和弱网中断尚未单独实测。
- 已有逐字稿支持时间戳跳转、搜索、导出和当前行高亮；译文由文本模型生成后可与原文双语显示。
- 「问这集」只检索当前单集；证据不足时明确标注，不跨节目检索。
- 云端转写只处理单集音频且上限 80 MiB，不支持说话人分离或长任务断点续传。
- 数据目录中的 SQLite 是唯一正式数据源；测试节目必须通过订阅或 OPML 显式导入。
- 候选 LPK 只在本机完成构建、lint 和打包内容冒烟；未在懒猫真机安装，网关身份、双账号隔离、手机 WebView 的长音频播放、重启和覆盖升级后的数据保留均待实测。部署时不要开启 `BOAI_ALLOW_PRIVATE_NETWORK` 或 `BOAI_ALLOW_INSECURE_AI`。
